# W3.6 Graph-viz page review

Compared `page:web` from Graph-viz immediately before W3.6 with the page
built from `(build:shell spec)`.

| Version | SHA-256 | Bytes |
| --- | --- | ---: |
| Before W3.6 | `e1ec0b686d0a47e74d24a4aa59c7fe34a344b7793fbc3dcb175bafa6c41ce05a` | 36,759 |
| After W3.6 | `0857e3fb5d610b7aeef3348da7b11c59d4cb0c22d49cb98b05eb05774c6259cc` | 36,817 |

The parsed documents each contain 671 structural and text events. After
sorting attributes, excluding the three new shell-contract attributes below,
and normalizing the equivalent parameterized theme bootstrap, every event is
identical. All existing element order, ids, roles, ARIA attributes, and text
are preserved.

The shell adds these `$area-spec.role` attributes:

- `aside#explorer-pane`: `data-role="reference"`
- `section#editor-pane`: `data-role="editor"`
- `section#preview-pane`: `data-role="result"`

The theme bootstrap has the same keys, accepted values, version check,
fallback, and DOM writes. W3.6 sources its storage key and version from the
consumer config, so quoting and whitespace differ.

The CSS digest remains unchanged. JavaScript changes because W3.6 fills the
previously empty `urui-config ++emit`, which Graph-viz already included in
its assembled bundle after W3.5.
