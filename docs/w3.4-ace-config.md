# W3.4: generated Ace configuration

Accepted adjustment, 2026-09-09: preserve configuration and initialization
behavior rather than requiring whitespace-only JavaScript changes.

`urui-ace.hoon ++config-js` takes an `ace-spec` and emits an external script.
The spec now includes `mode`; `mode` and `exts` use full Ace module ids.
Graph-viz uses `ace/mode/dot`; the fixture uses Ace's built-in text mode.

Graph-viz still serves `/apps/graph-viz/ace/graph-viz-config.js` as
`text/javascript; charset=utf-8`. Its static desk file was removed. The old
script remains only as the consumer's test fixture:
`tests/browser/real/fixtures/legacy-ace-config.js`.

The generated script changes these source details:

- `configureGraphVizAce` becomes the generic initializer `configureAce`.
- String values and the global property name are JSON-escaped. Publication
  uses a bracket accessor, so names need not be JavaScript identifiers.
- The configuration is built as JSON, with different key order and quoting.
  Its extensions and outer object are both frozen before publication.
- The missing-runtime error becomes `Could not load the Ace runtime`.

The configuration object is deep-equal to the legacy object's values. The
four path-setting calls and `loadWorkerFromBlob = false` call retain their
values and order. The global remains `graphVizAceAssets`; worker policy,
extension ids, themes, DOT mode, and version remain unchanged.

Reproduce the generated digest from the urui checkout:

```sh
VERE=/path/to/urbit bin/asset-digest.sh --consumer ../graph-viz \
  --assets ace-config-js
```

The existing asset test checks every Graph-viz route, content type, module,
version, and same-origin request. Its added comparison executes the served
script and legacy fixture, comparing configuration, setup calls, and both
freeze states. urui's Node test executes adversarial quoted/newline values,
an arbitrary global name, empty extensions, enabled workers, and the
missing-runtime branch. Hoon tests cover emitted consumer data and escaping.

Nine shared files are synced individually: seven JavaScript modules,
license, and README. Vendor module and license bytes are unchanged;
`mode-dot.js` stays application-owned. The fixture browser harness serves
the runtime, generated config, and upstream settings-menu URL, and its Ace
test creates a real text editor and loads all configured modules.

All six page/CSS/application-JavaScript digests retain the W3.3 baselines.
